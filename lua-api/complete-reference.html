🎮 Game (ITMGame)

The main game interface. This is your entry point for accessing the game world, players, and global functionality.

Properties

Property Type Description
Map ITMMap The current game map.
EntityManager ITMEntityManager Manager for spawning and removing entities.
EnvManager ITMEnvManager Environment manager for weather and effects.
IsHost bool True if the local player is the host or game is singleplayer.
IsMultiplayer bool True if the game is multiplayer.
DifficultyOptions DifficultyOptions Current difficulty settings.

Key Methods

GetPlayer(gamerName)

Get a player by their name.

Parameters:

  • gamerName (string): The name of the player.

Returns: ITMPlayer or null

Example: 
local player = game:GetPlayer("PlayerName")
if player then
    print("Found player: " .. player.GamerID)
end

GetAllPlayers(resultList)

Get all players in the game.

Parameters:

  • resultList (List<ITMPlayer>): List to populate with players.
Example: 
local players = {}
game:GetAllPlayers(players)
for _, player in ipairs(players) do
    print("Player: " .. player.GamerID .. " Health: " .. player.Health)
end

AddNotification(message, color, recipient)

Add a notification to the top-left of the screen.

Parameters:

  • message (string): Notification text.
  • color (Color, optional): Notification background color.
  • recipient (NotifyRecipient): Who receives the notification.
Example: 
game:AddNotification("Welcome to the game!", Color.Green, NotifyRecipient.AllPlayers)

AddEventBlockMined(blockID, action)

Register a callback when a block is mined.

Parameters:

  • blockID (Block): Block type or Block.None for all blocks.
  • action (function): Callback with parameters (Block, byte, GlobalPoint3D, ITMHand).
Example: 
game:AddEventBlockMined(Block.Stone, function(block, auxData, position, hand)
    print("Mined " .. block)
    local player = hand.Owner
    player.Health = player.Health - 5
end)

AddEventBlockPlaced(blockID, action)

Register a callback when a block is placed.

Example: 
game:AddEventBlockPlaced(Block.Dirt, function(block, position, hand)
    print("Placed dirt at " .. position.X .. ", " .. position.Y .. ", " .. position.Z)
end)

👤 Player (ITMPlayer)

Represents a human player. Extends ITMActor with additional player-specific features.

Additional Properties

Property Type Description
LocalIndex int Local controller index (0-3).
Inventory Inventory Player's inventory.
IsHuman bool Always true for players.
📝 Note: Player inherits all properties and methods from ITMActor. See the Actor section below for the full list.

🧟 Actor (ITMActor)

The primary object representing any actor in the game (player, NPC, mob, etc.).

Position & Movement Properties

Property Type Description
Position Vector3 Actor position in world space. Origin is bottom center of feet.
Velocity Vector3 Current velocity in meters per second.
EyePosition Vector3 Position of actor's eyes in world space.
ViewDirection Vector3 Normalized view direction.
SpeedOverride float Override standard actor speed.

Health & Status Properties

Property Type Description
Health float Current health.
MaxHealth float Maximum health this actor can have.
Stamina float Current stamina.
MaxStamina float Maximum stamina this actor can have.
Oxygen float Current oxygen level.
MaxOxygen float Maximum oxygen this actor can have.

State Properties

Property Type Description
IsPlayer bool True if this actor is a player.
IsOnGround bool True if actor is on a solid block.
IsCrouching bool True if actor is crouching.
IsDeadOrInactiveOrDisabled bool True if actor is inactive/dead. Always check this!
GamerID string Unique identifier for this actor.
FlyMode FlyMode Current flight mode (None, Flying, Spectator).

Key Methods

TakeDamageAndDisplay(damageType, amount, source)

Apply damage to the actor.

Example: 
player:TakeDamageAndDisplay(DamageType.Physical, 10, player.Position)

Strike(attacker, strikeInfo, damageOut)

Strike this actor, dealing damage based on combat rules.

Example: 
local strikeInfo = StrikeInfo.new()
strikeInfo.Damage = 25
strikeInfo.Type = DamageType.Physical
local damageDealt = 0
local wasHit = enemy:Strike(player, strikeInfo, damageDealt)
print("Damage dealt: " .. damageDealt)

TeleportTo(newPosition)

Teleport actor to a position.

Example: 
player:TeleportTo(Vector3.new(0, 50, 0))

LineOfSightTest(targetPosition, maxDistance)

Test if there's line of sight to a position.

Example: 
if player:LineOfSightTest(targetPosition, 100) then
    print("Can see target")
end

GetSkillLevel(skillType)

Get a skill level.

Example: 
local miningLevel = player:GetSkillLevel(SkillType.Mining)
print("Mining level: " .. miningLevel)

AddToInventory(inventoryItem, slotOut)

Add an item to the actor's inventory.

Example: 
local item = InventoryItem.new()
item.Item = Item.Dirt
item.Count = 64
local slotNum = 0
player:AddToInventory(item, slotNum)
print("Added to slot: " .. slotNum)

Hooks

Access to thread-safe hook collection for modifying behavior.

Example: 
player.Hooks:AddHook(myCustomHook, 0)

🗺️ Map (ITMMap)

The game map. Maps are made up of regions, which are made up of chunks.

Properties

Property Type Description
TileSize float Size of a map tile in meters.
MapSize int Total size of the map.

Key Methods

GetBlockID(point)

Get the block ID at a voxel location.

💡 Tip: Use GetBlockIDNoCache() for scattered queries to save memory.
Example: 
local block = map:GetBlockID(GlobalPoint3D.new(100, 50, 100))
if block == Block.Stone then
    print("Block is stone")
end

GetPoint(position)

Convert world position to voxel coordinates.

Example: 
local point = map:GetPoint(Vector3.new(0, 0, 0))

GetPosition(point)

Convert voxel coordinates to world position (top northwest corner).

IsValidPoint(point)

Check if a voxel is within map bounds.

Example: 
if map:IsValidPoint(point) then
    print("Point is in bounds")
end

Commit()

Force mesh rebuilds after map changes.

⚠️ Important: Call this after modifying blocks to update visuals.
Example: 
-- Modify blocks here
map:Commit()

❤️ Health Block (ITMHealthBlock)

Represents a destructible block with health.

Strike(attacker, strikeInfo, transmit)

Strike this health block, dealing damage.

Parameters:

  • attacker (ITMActor, optional): The attacker.
  • strikeInfo (StrikeInfo): Strike information.
  • transmit (bool): Whether to network the damage.

Returns: bool - true if block took damage

Example: 
local strikeInfo = StrikeInfo.new()
strikeInfo.Damage = 20
strikeInfo.Type = DamageType.Physical
if healthBlock:Strike(player, strikeInfo, true) then
    print("Health block was damaged")
end

👹 Entity Manager (ITMEntityManager)

Manages spawning and removing entities.

AddEntity(id, type, entity, transmit)

Add an entity to the world.

Example: 
local entity = Entity.new()
entity.Position = Vector3.new(0, 50, 0)
entityManager:AddEntity("myEntity1", "CustomMob", entity, true)

RemoveEntity(entity)

Remove an entity from the world.

⛈️ Environment Manager (ITMEnvManager)

Manages weather and environmental effects.

AddRain(position, rainDensity, rainSize, windX, windZ, color, transmit)

Add rain to an area.

Example: 
local rainPos = GlobalPoint3D.new(0, 0, 0)
envManager:AddRain(rainPos, 0.8, 0.5, 1.0, 0.5, Color.Blue, true)

RemoveRain(position, transmit)

Remove rain from an area.

AddFog(position, density, startDist, endDist, verticalDensity, color, duration, transmit)

Add fog effect.

Example: 
envManager:AddFog(
    GlobalPoint3D.new(0, 0, 0),
    0.5,
    10,
    100,
    1.0,
    Color.new(100, 100, 100),
    5000,  -- Duration in ms
    true
)

RemoveFog(position, transmit)

Remove fog.

AddHail(position, density, size, windX, windZ, color, hailSize, hailGravity, transmit)

Add hail (ice rain).

RemoveHail(position, transmit)

Remove hail.

🎣 Hooks System

Hooks allow you to intercept and modify game behavior. All hooks are thread-safe.

Hook Interface

AddHook(hook, priority)

Add a hook to the collection.

Parameters:

  • hook (IHook): Hook to add.
  • priority (int): Execution priority (lower runs first).

RemoveHook(hook)

Remove a hook.

Returns: bool - true if removed

🔧 Modifier Hooks

Modifier hooks allow you to change values in real-time.

ModifyDamageDealtHook

Modify outgoing damage (50% amplification example).

Example: 
local DamageHook = {}
function DamageHook:OnModifyDamageDealt(actor, target, weapon, damage)
    damage.Damage = damage.Damage * 1.5
end

actor.Hooks:AddHook(DamageHook)

ModifyDamageTakenHook

Modify incoming damage.

Example: 
local DefenseHook = {}
function DefenseHook:OnModifyDamageTaken(actor, attacker, weapon, damage)
    if actor.IsPlayer and actor.Health < 10 then
        damage.Multiplier = 0  -- Invincible when low health
    end
end

ModifyMaxHealthHook

Modify maximum health (called every frame).

Example: 
local HealthBoostHook = {}
function HealthBoostHook:OnModifyMaxHealth(actor, maxHealth)
    maxHealth.Value = actor.MaxHealth + 100
end

ModifyMovementSpeedMultiplierHook

Modify movement speed.

Example: 
local SpeedHook = {}
function SpeedHook:OnModifyMovementSpeedMultiplier(actor, speed)
    speed.Value = speed.Value * 2  -- Double speed
end

ModifyMaxJumpCountHook

Allow multi-jump.

Example: 
local TripleJumpHook = {}
function TripleJumpHook:OnModifyMaxJumpCount(actor, jumpCount)
    jumpCount.Value = 3  -- Triple jump
end

ModifyXPGainHook

Modify XP gained.

Example: 
local XPBoostHook = {}
function XPBoostHook:OnModifyXPGain(actor, skill, item, target, xp)
    xp.Value = xp.Value * 2  -- Double XP gain
end

❓ Condition Hooks

Condition hooks allow you to allow/prevent actions.

CanPlaceBlockHook

Control block placement.

Example: 
local PlacementHook = {}
function PlacementHook:OnCanPlaceBlock(actor, hand, block, position, isCanceled)
    if not actor.IsPlayer then
        isCanceled.Value = true  -- Only players can place
    end
end

CanMineBlockHook

Control block mining.

Example: 
local MiningHook = {}
function MiningHook:OnCanMineBlock(actor, hand, block, position, isCanceled)
    if block == Block.Obsidian then
        isCanceled.Value = true  -- Can't mine obsidian
    end
end

CanBlockAttackHook

Control attack blocking.

CanSwingHook

Control weapon swinging.

CanJumpHook

Control jumping.

CanSprintHook

Control sprinting.

📢 Event Hooks

Event hooks fire when something happens.

OnDamageDealtHook

Fired when actor deals damage.

Example: 
local DamageLogHook = {}
function DamageLogHook:OnDamageDealt(actor, target, weapon, damage)
    print(actor.GamerID .. " dealt " .. damage.Damage .. " damage to " .. target.GamerID)
end

OnDamageTakenHook

Fired when actor takes damage.

Example: 
local HurtLogHook = {}
function HurtLogHook:OnDamageTaken(actor, attacker, weapon, damage)
    print(actor.GamerID .. " took " .. damage.Damage .. " damage")
end

OnDeathHook

Fired when actor dies.

Example: 
local DeathHook = {}
function DeathHook:OnDeath(actor, attacker, deathType)
    print(actor.GamerID .. " has died")
    game:AddNotification(actor.GamerID .. " was slain", Color.Red, NotifyRecipient.AllPlayers)
end

OnBlockBrokenHook

Fired when block is broken.

OnBlockPlacedHook

Fired when block is placed.

OnLevelUpHook

Fired when actor levels up.

Example: 
local LevelUpHook = {}
function LevelUpHook:OnLevelUp(actor, skill)
    print(actor.GamerID .. " leveled up " .. skill)
    actor:TakeDamageAndDisplay(DamageType.Physical, -10, actor.Position)  -- Heal
end

OnItemCraftedHook

Fired when item is crafted.

💡 Comprehensive Examples

Example 1: Healing System

-- Heal a player to full health
function HealPlayer(player)
    player.Health = player.MaxHealth
    player.Oxygen = player.MaxOxygen
    player.Stamina = player.MaxStamina
    game:AddNotification(player.GamerID .. " has been healed!", Color.Green, NotifyRecipient.AllPlayers)
end

-- Usage
local player = game:GetPlayer("PlayerName")
if player then
    HealPlayer(player)
end

Example 2: Multi-Jump Ability

-- Enable triple jump for all players
local MultiJumpHook = {}
function MultiJumpHook:OnModifyMaxJumpCount(actor, jumpCount)
    jumpCount.Value = 3  -- Triple jump
end

local players = {}
game:GetAllPlayers(players)
for _, player in ipairs(players) do
    player.Hooks:AddHook(MultiJumpHook)
end

Example 3: Block Mining Event

-- Register event to track block mining
game:AddEventBlockMined(Block.None, function(block, auxData, position, hand)
    local player = hand.Owner
    if player then
        print(player.GamerID .. " mined " .. block)

        -- Award XP bonus
        local skillLevel = player:GetSkillLevel(SkillType.Mining)
        print("Mining level: " .. skillLevel)
    end
end)

Example 4: Damage Amplification Hook

-- Create a hook to amplify all damage dealt
local DamageAmplifyHook = {}
function DamageAmplifyHook:OnModifyDamageDealt(actor, target, weapon, damage)
    damage.Damage = damage.Damage * 1.5  -- 50% more damage
    print("Amplified damage to: " .. damage.Damage)
end

-- Add hook to player
local player = game:GetPlayer("PlayerName")
if player then
    player.Hooks:AddHook(DamageAmplifyHook, 10)
end

Example 5: Give Items to Player

-- Give player an item
function GiveItem(player, item, count)
    local invItem = InventoryItem.new()
    invItem.Item = item
    invItem.Count = count

    local slotNum = 0
    player:AddToInventory(invItem, slotNum)

    print("Added " .. count .. "x " .. item .. " to slot " .. slotNum)
end

-- Usage
local player = game:GetPlayer("PlayerName")
if player then
    GiveItem(player, Item.Sword, 1)
    GiveItem(player, Item.Dirt, 64)
end

Example 6: Line of Sight Checking

-- Check if actor can see target
function IsNearby(actor, target, maxDistance)
    local distance = Vector3.Distance(actor.Position, target.Position)
    if distance > maxDistance then
        return false
    end

    return actor:LineOfSightTest(target.EyePosition, maxDistance)
end

-- Usage
local enemy = GetEnemyActor()
local player = game:GetPlayer("PlayerName")
if enemy and player and IsNearby(enemy, player, 50) then
    print("Enemy can see player!")
end

Example 7: Weather System

-- Add rain and fog at player location
function AddStorm(player)
    local map = game.Map
    local point = map:GetPoint(player.Position)
    local envManager = game.EnvManager

    -- Add rain
    envManager:AddRain(point, 1.0, 1.0, 2.0, 1.0, Color.Blue, true)

    -- Add fog
    envManager:AddFog(point, 0.8, 20, 80, 1.0, Color.Gray, 10000, true)

    game:AddNotification("Storm incoming!", Color.Yellow, NotifyRecipient.AllPlayers)
end

Example 8: Getting Block Data

-- Check what block is at position
local map = game.Map
local position = Vector3.new(100, 50, 100)
local point = map:GetPoint(position)

if map:IsValidPoint(point) then
    local blockData = map:GetBlockData(point)
    print("Block: " .. blockData.BlockID)
    print("Light: " .. blockData.Light)
    print("Aux: " .. blockData.Aux)
else
    print("Position is out of bounds")
end

🎯 Best Practices & Patterns

Pattern 1: Player Loop

local players = {}
game:GetAllPlayers(players)
for _, player in ipairs(players) do
    if not player.IsDeadOrInactiveOrDisabled then
        -- Do something with player
    end
end

Pattern 2: Safe Actor Interaction

local player = game:GetPlayer("PlayerName")
if player and not player.IsDeadOrInactiveOrDisabled then
    -- Safe to interact with player
    player.Health = player.Health - 10
end

Pattern 3: Conditional Damage

local strikeInfo = StrikeInfo.new()
strikeInfo.Damage = 10
strikeInfo.Type = DamageType.Physical
strikeInfo.Source = attacker.Position

local damageDealt = 0
local wasHit = target:Strike(attacker, strikeInfo, damageDealt)
if wasHit then
    print("Hit! Damage dealt: " .. damageDealt)
end

🐛 Debugging Tips

1. Use AddNotification for in-game debugging: 
game:AddNotification("Debug: " .. value, Color.Yellow, NotifyRecipient.Local)
2. Always check IsDeadOrInactiveOrDisabled: 
if not actor.IsDeadOrInactiveOrDisabled then
    -- Safe to use actor
end
3. Print positions to verify: 
print("Position: " .. actor.Position.X .. ", " .. actor.Position.Y .. ", " .. actor.Position.Z)
4. Test hooks independently before combining: 
-- Test each hook separately first, then combine
5. Remember to call Commit() after map changes: 
-- Modify blocks
map:Commit()  -- Update visuals
