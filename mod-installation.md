## Overview

Mods add new features, scripts, and gameplay mechanics to Total Miner. This guide explains how to install them safely.

---

## Requirements

- A working copy of **Total Miner**  
- Access to your **game files**  
- Mod files from trusted sources (like this site)

---

## Installation Steps

1. **Download the mod** from the Mods page.  
2. **Locate your Total Miner mods folder** (path depends on platform).  
3. **Copy the mod files** into the mods folder.  
4. **Launch Total Miner** and enable the mod if required.  

---

## Updating Mods

- Replace old mod files with new versions.  
- Check for compatibility notes from the mod author.  

---

## Troubleshooting

- If the game crashes, remove the mod and try again.  
- Make sure you’re using the correct version of the game.  
- Check for conflicting mods.
